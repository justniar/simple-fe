# My Dream Travel Destination - Landing Page

## Project Description
This is a simple, responsive **landing page** built using **HTML5** and **Bootstrap 5**. The website showcases a dream travel destination with sections for attractions, food, travel tips, and contact information.

## Features
- **Navigation Section** 
- **Hero Section** 
- **About the Destination** 
- **Top Attractions** 
- **Local Cuisine**
- **Travel Tips** 
- **Contact Section** 
- **Responsive Design**

## Technologies Used
- **HTML5**
- **CSS3**
- **Bootstrap 5**
- **Google Fonts**
- **FontAwesome Icons**

## How to Run This Project

### 1. Download or Clone the Repository
```sh
git clone https://github.com/yourusername/travel-landing-page.git
```

### 2. Open the Project Folder
```sh
cd simple-fe
```

### 3. Open the `index.html` File in a Browser
Simply double-click the `index.html` file, or open it in a browser manually.

### 4. (Optional) Run a Local Server
If you prefer running it with a local server, you can use Python:
```sh
# For Python 3
python -m http.server
```
Then, open `http://localhost:8000` in your browser.

## Customization
- You can **change the destination** by editing the text and images in `index.html`.
- Modify colors and styles in the `styles.css` file.
- Add more Bootstrap components as needed.
